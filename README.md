# Yunpeng Chu Academic Homepage

A clean, self-contained multi-page academic homepage for GitHub Pages.

## Navigation

- About Me: `/`
- Publications: `/publications/`
- Services: `/services/`
- Awards: `/awards/`

The wording and page organization intentionally follow the original website. The redesign changes presentation and site structure, not the substantive page content.

## Deploy

1. Back up the current repository.
2. Copy the contents of this folder to the root of `yunpeng2004.github.io`.
3. In GitHub → Settings → Pages, deploy from `main` / `(root)`.
4. Remove any old custom domain in Settings → Pages if you want to use `https://yunpeng2004.github.io`.

No external theme, font CDN, icon library, analytics service, Disqus, or third-party site assets are required.
